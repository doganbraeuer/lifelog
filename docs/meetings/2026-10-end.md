# Meeting at the end of October 2026

Prof. Pree, Dogan Bräuer, Dylan Müller (group 2).

## Decisions

- **A platform, not a single app.** Health is the first use case; later
  modules could be a calorie counter, recipes or sport. Hence `module` in the
  API and the module catalog in the app.
- **No local language model** any more (before, everything was planned to
  run locally). A vision model in the cloud reads the documents.
- **Stack:** backend in Go, app in Flutter for iOS and Android, MongoDB
  including vectors for retrieval (RAG).
